# CodeBook Network Analyzer

A Python project built while learning data analysis concepts and JSON data processing. This project explores user profiles, friendship connections, and page preferences from a social media platform dataset using pure Python.

## Features

* Load and parse JSON data
* Display user details and connections
* Explore friendship networks
* Analyze page preferences
* Built using Python's built-in modules

## Tech Stack

* Python 3
* JSON
* File Handling

## Learning Objectives

* Working with JSON datasets
* Data exploration using Python
* Understanding social network structures
* Writing clean and modular code

🚧 Currently under development as part of a Data Science learning journey.
